## Compatibility and support

Default transport ceiling remains 1452 bytes. `Transport.ConfigurePacketCeilingV1` accepts 1452–8972 before initialization; peer/path limits can lower the effective size. Jumbo is experimental, intended for operator-managed MTU 9000 links, and includes shrink recovery without a recovery-time guarantee. It cannot be combined with `ConfigureMultipathIOV1`, in either order. Loopback and unit evidence do not qualify a physical link or promise a throughput increase. [F12 (#1226)](https://github.com/the-sarge/quic-go-fast/issues/1226) explicitly allows this earlier experimental release and remains separate.

The supported multipath profile is experimental opt-in draft-21 QUIC v1, Linux amd64, one or two paths and exact unconnected native UDP socket grants. Reno remains default. Reno and explicitly selected BBR support primary/backup; only BBR supports uncoupled paced byte-round-robin aggregate. Other platforms and excluded configuration combinations refuse activation. Disabled/unnegotiated connections stay ordinary. Additional validated paths begin as local backups; each sending endpoint must activate paths with `Path.SetLocalUseV1("active")` to use them concurrently. The [usage guide](../usage.md#packet-io-and-socket-ownership) owns constructor behavior, grant-wide routing (including ordinary connections and public writes), the 4,096-participant bound, shutdown/join and socket-ownership obligations. The [B12 support record](../audits/2026-11-15-bbr-b12-support.md) supersedes earlier BBR/aggregate refusal statements; it does not qualify the underlying BBR controller or recommend adoption.

The application DATAGRAM send queue grows from 32 to 128 entries for ordinary/unregistered and granted connections, including existing `SendDatagram` users. Producers reach backpressure later, and retention can increase. Queue storage grows lazily, with no fill wait or payload preallocation. At the recorded 1,190-byte payload, the additional 96 entries represent 114,240 logical payload bytes plus metadata per queue; this entry bound does not limit caller backing, blocked-sender copies or recovery retention. The [application admission policy](../agents/owned-datagram-admission-1292.md#current-application-admission-policy) and [production-repair receipt](../audits/2026-11-12-r18-production-repair.md) retain the decision and measured costs. Existing copying DATAGRAM APIs remain. `SendDatagramOwnedContextV1` transfers payload storage only on success, and recovery can retain that storage; use standalone appropriately sized allocations and never reuse transferred storage. `SealDatagramAdmissionV1` permanently fences later sends with its terminal cause while receive draining remains available. `SendDatagramContext` provides cancellable copying admission.

HTTP/3 now rejects previously accepted malformed status strings, missing regular-request schemes and invalid authority bytes in HTTP(S)/plain CONNECT. Status must be three digits in 100–599; 101 is handled in the bounded informational-response loop until a final response. Authority checking validates allowed bytes, not full host/port syntax. Other-scheme and CONNECT distinctions remain. QUIC v2 key updates use the correct v2 label; v1 remains unchanged. These are observable corrections, not new optional features.

Multipath adds configuration (`Config.ConfigureMultipathV1`, `MultipathEnabledV1`), socket grant/join (`Transport.ConfigureMultipathIOV1`, `WaitMultipathIOStoppedV1`), connection discovery/lifetime (`Conn.MultipathNegotiatedV1`, `OpenPathV1`, `PathsV1`, `PathChangesV1`, `WaitTransportDetachedV1`), and path control (`Path.PathIDV1`, `StateV1`, `MigrateV1`, `SetLocalUseV1`, `AdvertiseStatusV1`, `AbandonV1`). `MultipathPathStateV1` and the `ErrMultipath*V1` sentinels expose state and failure categories. The [public API source](../../multipath_api.go) and [grant/error definitions](../../external_packet_io.go) define exact contracts.

Qlog adds `PathIdentity`, `PathLifecycleUpdated` (`transport:path_lifecycle_updated`) and the draft-21 `PathAbandonFrame`, `PathStatusFrame`, `PathNewConnectionIDFrame`, `PathRetireConnectionIDFrame`, `MaxPathIDFrame`, `PathsBlockedFrame` and `PathCIDsBlockedFrame` aliases/encodings. Existing `PacketSent`, `PacketReceived`, `MTUUpdated` and `PacketLost` structs gain a `Path` field: positional literals for these structs stop compiling and must become keyed literals. The path identity and lifecycle event are fork diagnostics, not a claim of qlog-schema standardization; ordinary connections omit path identity. See [events](../../qlog/event.go) and [frames](../../qlog/frame.go).

Keyed `Config` literals remain the supported source form; positional literals were already unsupported by earlier fork releases. Fork-only calls should remain isolated in an integration adapter. No independent module/repository identity cutover is part of fast.10.

The [full evaluation](../audits/frame-sorter-1410/README.md) retains the tested workload and host limits. |
