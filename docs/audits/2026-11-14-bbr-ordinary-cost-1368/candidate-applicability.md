## Actual geometry and admission contract

The selected ordinary branch requires a confirmed handshake, BBR policy, a native local sender that is also the queue, no multipath registry, no selected route and current packet size M ≤ 1,452. The pure planner still computes the maximum N from recovery and pacing allowance. With GSO it uses the 65,507-byte UDP payload ceiling, rounds down to whole M-sized packets and preserves the 64-segment construction cap. Without GSO, N = M. The maximum full-size geometry is 45 packets / 65,340 bytes at M = 1,452 or 54 packets / 64,800 bytes at M = 1,200; those are upper bounds, not observed averages.

Under `localSendCredit.mu`, `reserveUpTo` validates M > 0 and N ≥ M and applies the existing ordinary, nonisolated `canReserve(M, 2Q, true, false)` predicate. That predicate preserves isolation and requires all pending debt to belong to the current generation. On success, reserve `floor(min(N, max(0, 2Q - pending)) / M) * M`; on failure, drain stale availability under the same lock before returning. The unchanged successful bookkeeping records pending/current bytes and reuses a reservation. Construction receives the actual grant, selects the 65,535-byte pool only above 20 KiB with GSO, releases unused allowance and charges actual admitted UDP bytes to pacing at the original opportunity timestamp. Q and 2Q are unchanged, as are the first absolute deadline and exactly-once worker retirement.

The request is now the whole-packet range [M,N] in this selected domain. Its admissibility and rearming predicate is therefore minimum M, not the former maximum N. The existing refusal handler retains the native construction reservation and offers bounded ACK/control work. If there is no ACK, it releases the unused exact-M control reservation before rearming; completion before rearming must re-signal when M fits, and completion after rearming signals normally. A connection-owned unused-reservation release alone must not spin. Generation debt may leave bounded control available; isolation, insufficient control room and physical queue capacity remain hard blocks. A true refusal must consume neither ordinary payload nor a packet number.

Reno, unregistered BBR, negotiated multipath, routed work, active jumbo packets, handshake/coalesced sends, steered work and exempt ACK/PTO/MTU work retain their exact reservation operations. Multipath readiness continues to test its original exact request. GSO-disabled eligible ordinary work uses the new operation with N = M, which is exact in effect. The frozen exact-operation equivalence oracle still tests the original exact operations; it does not claim that the deliberately new range operation is equivalent to exact-N refusal.

The larger protected representation is separately guarded by active opportunity, paced ordinary reservation above 20 KiB, current-standard/native selection and current GSO decision. Existing Reno and active-jumbo coalesced buffers do not acquire deferred protection from the constructor extension alone. Unsupported sealers and tracing-related synchronous fallback preserve the complete admitted prefix and release the existing plan through the established owner. Larger encryption before native submission, reservation size, storage backing and handoff frequency remain real tradeoffs; unchanged owner source does not erase them.
